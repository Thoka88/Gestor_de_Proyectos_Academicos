Gestor de Proyectos Académicos

Descripción del Proyecto
El Gestor de Proyectos Académicos es una aplicación desarrollada en C# que permite a profesores y estudiantes registrar, organizar y dar seguimiento a proyectos y tareas académicas.  
El sistema gestiona usuarios con distintos roles, controla el avance de tareas y genera reportes de progreso, facilitando la planificación y el control del trabajo académico.

---

Requisitos Técnicos

- Lenguaje: C#
- Framework: .NET (ASP.NET MVC o Web Forms)
- Base de datos: SQL Server Management Studio 2022 
- Control de versiones: Git y GitHub  
- Entorno de desarrollo recomendado: Visual Studio 2022 o superior  

Librerías / tecnologías utilizadas:
- System.Data.SqlClient (o Microsoft.Data.SqlClient)
- BootStrap
- SweetAlert2
